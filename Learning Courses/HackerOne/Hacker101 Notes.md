# Hacker 101

## Introduction

Key things to learn:

- How to identify, exploit and remediate the top web security vulnerabilities, as well as arcane bugs.
- How to properly handle cryptography.
- How to design and review applications from a security standpoint.
- How to operate as a bug bounty hunter/security consultant.

Things needed to get started:

- Be able to run Java Applications. Understand using web requests and Burp Suite/the python requests package.
